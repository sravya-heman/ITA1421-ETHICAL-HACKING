# ITA1421-ETHICAL-HACKING
# 🔐 Ethical Hacking

## 📌 About

This repository contains practical exercises, Linux commands, network scanning techniques, and cybersecurity concepts studied as part of the Ethical Hacking course.

The main objective is to understand security vulnerabilities, learn ethical hacking methodologies, and develop skills to identify and prevent cyber threats.

## 🎯 Objectives

* Understand ethical hacking principles and cybersecurity ethics.
* Learn footprinting and social engineering techniques.
* Perform basic network scanning using Nmap.
* Understand web application and network vulnerabilities.
* Explore Windows and Linux operating system security.
* Learn vulnerability prevention and responsible disclosure.

## 📚 Topics Covered

* **Unit I:** Ethical Hacking Overview
* **Unit II:** Footprinting and Social Engineering
* **Unit III:** Service Scanning and Enumeration
* **Unit IV:** Hacking Networks and Web Applications
* **Unit V:** Hacking Operating Systems

## 🛠️ Tools and Technologies

* Kali Linux

## 💻 Practical Exercises

* Basic Linux commands
* Network discovery and port scanning
* Service version detection
* Operating system detection
* Footprinting and DNS information gathering
* Vulnerability identification
* Security assessment and reporting

## 🔍 Example: Nmap Commands

**1. Basic Network Scan**

```bash
nmap 192.168.1.10
```

**2. Service Version Detection**

```bash
nmap -sV 192.168.1.10
```

**3. Operating System Detection**

```bash
nmap -O 192.168.1.10
```

Replace the example IP address with a target you own or are explicitly authorized to test.

## 🛡️ Ethical Guidelines

* Obtain authorization before testing any system.
* Stay within the approved testing scope.
* Protect confidential and personal information.
* Avoid unnecessary disruption or damage.
* Report vulnerabilities responsibly.
* Use cybersecurity tools only for lawful and educational purposes.

## 🎓 Learning Outcomes

* Understand fundamental cybersecurity concepts.
* Gain practical experience with Linux and security tools.
* Identify common network and application security weaknesses.
* Apply ethical principles during security assessments.

This repository is intended for educational purposes only. All security testing must be performed on systems you own or have explicit permission to assess. Unauthorized access or testing may violate applicable laws.
